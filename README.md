# زجاج سكريت – موقع ثنائي اللغة

موقع ثابت ثنائي اللغة (العربية / English) مخصص لخدمات الزجاج السكريت في مدينة الرياض، المملكة العربية السعودية. بُني باستخدام **Astro 7 + TypeScript** مع تركيز على **SEO فني**، **إمكانية الوصول**، **أداء خفيف**، وتحويل مباشر عبر الهاتف والواتساب.

## الأوامر المتاحة

| الأمر | الوصف |
|---|---|
| `npm run dev` | تشغيل الخادم المحلي للتطوير مع إعادة التحميل التلقائي |
| `npm run build` | بناء الموقع الثابت إلى مجلد `dist/` |
| `npm run preview` | معاينة البناء المحلي قبل النشر |
| `npm run check` | فحص TypeScript مع Astro |
| `npm run verify` | تشغيل فحص شامل بعد البناء (عناوين، روابط، hreflang، JSON-LD...) |
| `npm run generate:assets` | إعادة توليد صور SVG Placeholder |

## هيكل المشروع

```text
src/
├── components/      # مكونات Astro القابلة لإعادة الاستخدام
├── config/          # إعدادات الموقع (site.ts)
├── data/            # بيانات الخدمات والصفحات الثنائية اللغة
├── layouts/         # قوالب الصفحات
├── pages/           # صفحات الموقع (AR + EN)
├── scripts/         # سكريبتات حركة وتأثيرات
└── styles/          # ملفات CSS
public/              # أصول ثابتة (صور، favicon)
scripts/             # سكريبتات مساعدة (توليد أصول + تحقق)
```

## البيانات والتخصيص

جميع البيانات المركزية موجودة في:

- `src/config/site.ts` – معلومات النشاط، أرقام الهاتف/واتساب، مسارات الصفحات
- `src/data/services.ts` – بيانات الـ8 خدمات بالعربية والإنجليزية + أسئلة شائعة
- `src/data/pages.ts` – محتوى الصفحات الثابتة (من نحن، سياسة الخصوصية، دليل الأسعار، معرض الأعمال)
- `src/data/home.ts` – محتوى الصفحة الرئيسية

## الصور

- الصور الافتراضية هي **SVG Placeholder** مخصصة لهذا المشروع فقط.
- جميعها تحت: `public/images/` و`public/images/services/`
- لا توجد صور حقيقية من عميل بعد. عند توفرها، استبدل كل ملف SVG بصورة حقيقية بنفس الاسم أو حدّث المسارات في `src/data/services.ts`.
- **لا تستخدم أبداً** صور من مشاريع سابقة أو مواقع منافسة.
- كل صورة تحتوي على `alt` وصفي مناسب.

## النشر على Netlify

1. اربط المستودع بموقع Netlify جديد
2. إعدادات البناء:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
3. أضف متغير البيئة عند شراء الدومين:
   - `SITE_URL` = `https://yourdomain.sa`
4. أعد النشر بعد إضافة المتغير

> عند عدم وجود `SITE_URL`، يبقى الموقع يستخدم مسارات نسبية في `canonical` و`hreflang` و`sitemap.xml` لتفادي نشر دومين وهمي. فور إضافة المتغير يتحول كل شيء لروابط مطلقة تلقائياً.

## تحسينات SEO

- ثنائي اللغة مع `hreflang` متبادل + `x-default`
- `canonical` صحيح لكل صفحة (ما عدا 404)
- بيانات منظمة: `Organization`، `WebSite`، `Service`، `BreadcrumbList`، `FAQPage`
- `sitemap.xml` و`robots.txt` ذكيان حسب حالة الدومين
- محتوى طبيعي بالعربية والإنجليزية، غير مترجم حرفياً
- تركيز على منطقة **الرياض فقط**
- لا توجد نماذج تواصل، فقط تحويل مباشر للهاتف والواتساب

## إمكانية الوصول والحركات

- `skip-link` للتنقل السريع
- دعم كامل لـ `RTL`/`LTR`
- مراعاة `prefers-reduced-motion`: يُعطّل GSAP وLenis تلقائياً
- Lenis يُفعّل فقط على أجهزة سطح مكتب ذات مؤشر دقيق
- المحتوى ظاهر بالكامل بدون JavaScript
